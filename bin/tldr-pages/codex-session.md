# codex-session

> Manage per-feature Codex worktree sandboxes (a git worktree plus an isolated Codex config).
> Personal script; see `codex-session --help`.

- Create a new session:

`codex-session new {{name}}`

- Open an existing session:

`codex-session open {{name}}`

- List all sessions:

`codex-session list`

- Delete a session:

`codex-session delete {{name}}`
