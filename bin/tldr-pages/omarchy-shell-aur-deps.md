# omarchy-shell-aur-deps

> List AUR-origin packages providing commands the Omarchy shell (quickshell) shells out to.
> Personal script; see `omarchy-shell-aur-deps --help`.

- List the AUR packages needed:

`omarchy-shell-aur-deps`

- Also show official-repo and unresolved commands found in the scan:

`omarchy-shell-aur-deps -v`
