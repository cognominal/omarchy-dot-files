# from-omarchy-shell

> Check whether a running process descends from the Omarchy shell (quickshell), by fork or via uwsm-app.
> Personal script; see `from-omarchy-shell --help`.

- Check a specific PID:

`from-omarchy-shell {{936170}}`

- Resolve the target by matching a process name/pattern instead of a PID:

`from-omarchy-shell -n {{wl-paste}}`
